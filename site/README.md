# Janob HR — landing sahifa

Marketing/tanishtiruv sayti. React + Vite + Tailwind CSS.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Build (production)

```bash
npm run build
```

Natija `dist/` papkasida — istalgan statik hosting (Vercel, Netlify, GitHub
Pages, Render Static Site) ga shu papkani joylashtirish kifoya.

## Muhit o'zgaruvchilari (ixtiyoriy)

- `PORT` — dev server porti (standart: 5000)
- `BASE_PATH` — sayt joylashadigan yo'l prefiksi (standart: `/`)
